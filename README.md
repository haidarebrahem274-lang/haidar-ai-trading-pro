# HAIDAR AI TRADING PRO

واجهة تحليل فني عربية تعمل من المتصفح، وتعرض مخطط شموع ومستويات تحليلية دون تنفيذ صفقات تلقائياً.

## التشغيل
- افتح `index.html` عبر GitHub Pages أو استضفه كصفحة ثابتة.
- اختر السوق والإطار الزمني وعدد الشموع ثم اضغط «تحليل السوق».
- أزواج العملات الرقمية المدعومة حالياً: BTCUSDT وETHUSDT وBNBUSDT وSOLUSDT عبر Binance Spot API.
- الأسواق الأخرى تتطلب مفتاح Twelve Data API صالحاً، وقد تختلف التغطية والحدود حسب الخطة والرمز والفريم.

## المؤشرات
EMA 20/50/200، RSI 14، MACD، ATR، وتصويت اتجاه تقريبي.
يشترط التطبيق توفر 300 شمعة مغلقة على الأقل قبل عرض نتيجة التحليل.

## تنبيهات مهمة
- درجات القوة والتوافق تقييمات فنية داخلية وليست احتمالات ربح أو ضمانات.
- أسعار مزود البيانات قد تختلف عن أسعار الوسيط، وقد تتغير قبل تنفيذ أي صفقة.
- لا ينفذ الموقع صفقات ولا يتصل بحساب تداول حقيقي.
- مفتاح Twelve Data يُدخل في المتصفح فقط في هذه النسخة؛ لا تستخدم مفتاحاً حساساً أو ذا صلاحيات مدفوعة/خاصة. الأفضل لاحقاً نقل طلبات البيانات إلى وسيط خلفي آمن وعدم تخزين المفاتيح في الواجهة.
- مكتبة Lightweight Charts تُحمّل من unpkg وتتطلب اتصالاً بالإنترنت.

## ملاحظة تقنية
هذه نسخة HTML ثابتة بملف واحد. لا تتضمن خادماً خلفياً أو نظام حفظ مفاتيح آمن أو سجل صفقات سحابي.
